# 资产配置记录应用 (Asset Allocation Record)

这是一个用于管理和可视化个人资产配置的现代化网页应用。

## 功能特点

- **多类型资产管理**：支持现金、股票、债券、基金、房产和其他投资。
- **实时总览**：自动计算总资产金额，实时更新。
- **可视化图表**：使用动态饼图展示资产分布，支持交互查看详情。
- **数据持久化**：所有数据保存在本地浏览器中，刷新不丢失，隐私安全。
- **响应式设计**：完美适配桌面、平板和移动设备。

## 使用说明

### 1. 启动项目

确保已安装 Node.js 环境。

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 2. 添加资产

1. 在左侧（移动端为上方）的"新增资产"卡片中操作。
2. 选择资产类型（如：股票）。
3. 输入资产金额（必须为正数）。
4. 点击"添加资产"按钮。

### 3. 查看与管理

- **总资产**：左上角显示当前所有资产的总金额。
- **资产分布**：中间的饼图直观展示各类资产占比，鼠标悬停可查看具体金额和百分比。
- **资产列表**：右侧（或下方）列出所有资产条目，点击垃圾桶图标可删除对应条目。

## 技术栈

- React 18
- TypeScript
- Tailwind CSS
- ECharts (echarts-for-react)
- Zustand (State Management)
- Vite

## 部署

构建生产环境版本：

```bash
npm run build
```

构建产物位于 `dist` 目录，可部署至任何静态网站托管服务（如 GitHub Pages, Vercel 等）。
